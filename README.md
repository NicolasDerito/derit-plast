# Derit Plast — sitio web

Sitio de Derit Plast (fábrica de plástico, Florencio Varela).

**Estado: maqueta / versión en prueba.** No es el sitio final. El formulario no envía y
todavía faltan fotos de producto.

- `index.html` — home
- `styles.css` — estilos
- `img/` — fotos de producto
- `logo-derit.png` — logo de la marca (depurado de la foto del cartel)
- `favicon.svg` — icono

HTML y CSS puro, sin build. Para verlo local:

    python3 -m http.server 4173

Los bloques de foto que quedan vacíos están así a propósito: falta el material.
Los datos que aparecen son los que confirmó el cliente.
