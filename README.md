# Derit Plast — sitio web

Maqueta del sitio de Derit Plast (fábrica de plástico, Florencio Varela).

**Estado: no publicada.** Es una página de revisión.

- `index.html` — home
- `styles.css` — estilos
- `logo-derit.png` — logo de la marca (depurado de la foto del cartel)
- `favicon.svg` — icono

HTML y CSS puro, sin build. Para verlo local:

    python3 -m http.server 4173

Los bloques de foto están vacíos a propósito: falta el material fotográfico.
Los datos que aparecen son los que confirmó el cliente.
